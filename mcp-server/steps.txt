Deploy kagent:
----------------

$ helm install kagent-crds oci://ghcr.io/kagent-dev/kagent/helm/kagent-crds \
      --version 0.10.1 \
      --namespace kagent \
      --create-namespace \
      --wait

$ export OPENAI_API_KEY="your-api-key-here"

Kagent can be used with OpenAI, Anthropic, Gemini, Azure OpenAI API keys or Ollama on local.
Refer to the official documentation for more details: https://kagent.dev/docs/kagent/0.x/introduction/installation/

$ helm install kagent oci://ghcr.io/kagent-dev/kagent/helm/kagent \
      --version 0.10.0 \
      --namespace kagent \
      --set providers.default=openAI \
      --set providers.openAI.apiKey=$OPENAI_API_KEY \
      --wait


Note: Run the following commands from the mcp-server directory.

Build MCP Server image and deploy MCP Server on the cluster
------------------------------------------------------------
$ docker build -t kubeplus-mcp:latest .
$ kubectl apply -f mcp-rbac.yaml -n kagent

$ export KUBEPLUS_NS="<kubeplus namespace>"
$ envsubst '$KUBEPLUS_NS' < mcpdeployment.yaml | kubectl apply -n kagent -f -


Build and deploy the KubePlus RAG MCP server
---------------------------------------------
The KubePlus RAG MCP server provides documentation retrieval over KubePlus documentation and example manifests.

Build the documentation index:
$ python3 kubeplus-rag/ingest.py

Build the RAG MCP server image:
$ docker build -t kubeplus-rag:latest ./kubeplus-rag

If using Minikube, load the image into Minikube:
$ minikube image load kubeplus-rag:latest

Deploy the RAG MCP server:
$ kubectl apply -f kubeplus-rag/kubeplus-rag.yaml -n kagent

Register the RAG MCP server with Kagent:
$ kubectl apply -f kubeplus-rag/kubeplus-rag-mcp.yaml -n kagent


Configure the KubePlus agent
----------------------------
The KubePlus agent uses both the KubePlus MCP server and the KubePlus RAG MCP server.

$ kubectl apply -f kubeplus-agent.yaml


Access the kagent dashboard:
----------------------------

$ kagent dashboard

Use the port-forwarding command provided by kagent dashboard:
$ kubectl port-forward -n kagent svc/kagent-ui 8082:8080

Open the dashboard UI in the browser:
http://localhost:8082/
