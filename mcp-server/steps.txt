Deploy kagent:
----------------
https://kagent.dev/docs/kagent/getting-started/quickstart/


Build MCP Server image and deploy MCP Server on the cluster
------------------------------------------------------------
docker build -t kubeplus-mcp:latest .
kubectl apply -f mcp-rbac.yaml -n kagent

export KUBEPLUS_NS="<kubeplus namespace>"
envsubst '$KUBEPLUS_NS' < mcpdeployment.yaml | kubectl apply -n kagent -f -
kubectl apply -f kubeplus-agent.yaml

kagent dashboard -> Start port forwarding
